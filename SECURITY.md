# Reporting a security weakness

Thank you for helping keep Abim Guard and its users safe.

If you think you have found a weakness in Abim Guard (for example, a way to make it miss malware, stop protecting, leak information, or run something it should not), please report it **privately**, so it can be fixed before anyone can misuse it.

**Please do not post security weaknesses in public issues.**

## How to report

Either:

- **On GitHub:** open the [Security tab](https://github.com/ladiran/Abim_Guard/security) and choose **Report a vulnerability**. Only the developer can see the report.
- **By email:** abimbola.oladiran@science.fulafia.edu.ng, with "Abim Guard security" in the subject.

Please include:

1. The Abim Guard version (shown on the Developer page in the app) and whether you installed it from the Microsoft Store or GitHub.
2. Your Windows version.
3. What you did, what you expected, and what happened instead. Steps to repeat it help a lot.

Do not send real malware as an attachment. Name the sample, or give its SHA-256 fingerprint or a link to it on MalwareBazaar, instead.

## What happens next

You will get a reply acknowledging the report. Once the weakness is confirmed, a fix is prepared, released on GitHub and sent to the Microsoft Store. With your permission, you will be thanked in the release notes.

## Supported versions

Only the latest version receives fixes. The Microsoft Store version updates automatically; GitHub users should download the [latest release](https://github.com/ladiran/Abim_Guard/releases/latest).
