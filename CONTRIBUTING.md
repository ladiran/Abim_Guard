# Feedback and contributions

Abim Guard is developed by one person, Oladiran Johnson Abimbola. Because it is a security tool, **code contributions are not accepted**: every change is written and reviewed within the project, so users can trust what they install. Pull requests from outside the project will be closed without merging.

Your ideas and reports are very welcome, though:

| You want to... | Do this |
|---|---|
| Report a security weakness | Follow [SECURITY.md](SECURITY.md). Please report it privately, not in a public issue |
| Report a bug | [Open a bug report](https://github.com/ladiran/Abim_Guard/issues/new?template=bug_report.yml) |
| Suggest a feature | [Suggest a feature](https://github.com/ladiran/Abim_Guard/issues/new?template=feature_request.yml) |
| Ask something else | Email abimbola.oladiran@science.fulafia.edu.ng |

You need a free GitHub account to open an issue. If you do not have one, email works just as well.

The source code stays public under the MIT licence, so anyone can read it and check what the app does.
